⌨️ Production CLI & Render Commands

Execute local renders, run comprehensive lint and WCAG contrast checks, or generate thumbnail master plates.

# 1. Full end-to-end draft build & timed render with performance recording:
node scripts/render-draft.mjs --version=10

# 2. Local 1080p Drawelement render using pinned Hyperframes 0.9.67:
cd video && npx --yes hyperframes@0.9.67 render --quality looks --output renders/draft-v10.mp4

# 3. Comprehensive Hyperframes lint, layout, and WCAG AA contrast check:
cd video && npm run check

# 4. Generate 1280x720 thumbnail designs via headless Chrome & FFmpeg:
scripts/build-thumbnails.sh
Render contract & zero-bloat policy: Video renders are deterministic and timed to milliseconds using GSAP timelines registered on window.__timelines. Heavy master 1080p MP4 files are published via GitHub Releases and Fly.io HTTP 206 streaming proxies rather than inflating git history.
