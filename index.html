🏗️ Architecture

How the pieces fit: you and Claude edit two source files, generators turn them into pages and media, GitHub Pages serves the site, Hyperframes renders the video, and your feedback loops back. Generated by scripts/build-architecture.mjs.

🌐Site pagesThe build scripts, plus nav.js, feedback.js and site.css loaded by every page.
🧩nav.js, feedback.jsversions data stamped into nav.js, and your browser's localStorage for notes and ticks.
🐙GitHub PagesA push to main. Pages caches for about 10 minutes, so assets carry a ?v= version.
🎬video/ projectGenerated by build-video.mjs from scenes.json (timings, text), plus assets/bg, assets/vo, the npm package hyperframes@0.9.67 and GSAP from a CDN.
⏱️render-draft.mjsbuild-video, the Hyperframes CLI (check, render), ffmpeg and gh (deploy history). Feeds the First draft, Review and Performance pages.
🧪run-tests.mjs, run-evals.mjsAutomated test suite (spec, server HTTP 206/CORS, syntax, review query state) and production evals (voiceover WPM pacing, hook retention, editorial compliance).
📼Final MP4The video project rendered by the Hyperframes CLI using headless Chrome and FFmpeg.
📣Publish page, thumbnailspublish.json, scenes.json (chapters), project.json (disclaimer); thumbnails need headless Chrome, ffmpeg and the fal.ai red-tape plate.
🤖Claude CodeAGENTS.md for the rules, your pasted feedback as input, git, and gh to check the deploy.
