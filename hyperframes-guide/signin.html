🔐 Hyperframes sign-in

Hyperframes has no separate web login page. You sign in with a HeyGen account, either from the command line or from the Studio app. For this project you do not need to sign in at all.

Do I need to sign in?

No, not for this project. You can create and render locally with no account. Voice falls back to the free Kokoro engine and music to local engines.

Sign in only if you want HeyGen voices and music, HeyGen's managed cloud rendering, the hosted MCP connector, or to own a published project you can update later.

Sign in from the command line

npx hyperframes auth login            # opens your browser for OAuth, then saves the session
npx hyperframes auth status           # shows who you are signed in as, and what is configured
npx hyperframes doctor                # checks the local dependencies

# CI or a machine with no browser: save an API key instead
npx hyperframes auth login --api-key

Signing in is the same OAuth step as creating an account: a new user lands on the sign-up screen.

Sign in from the Studio app

  1. Install the app from hyperframes.studio.
  2. On first launch choose Continue with HeyGen. Your browser opens the sign-in page.
  3. Sign in within 10 minutes. The browser sends you back to the app, which shows "You're in!".

Keeping your credentials safe

  • The CLI stores the session in ~/.hyperframes/credentials, outside this repo. Do not copy it into the project.
  • This repo is public. Never commit an API key or paste one into chat. Keys go in a git-ignored .env (this project already uses one for FAL_KEY).
  • If a key leaks, revoke it in the provider's dashboard and create a new one.
