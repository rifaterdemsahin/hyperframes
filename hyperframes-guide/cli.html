⌨️ CLI cheat sheet

The commands used on this project. Run them from video/. Version pinned in package.json: 0.9.67.

From the project's own CLAUDE.md and hyperframes --help. Run npx hyperframes docs <topic> for offline reference.

Daily loop

npm run check                          # lint + runtime + layout + motion + contrast
npx hyperframes snapshot --at 1,3,5    # PNG frames at those seconds
npm run render                         # render to MP4
npx hyperframes lint --verbose         # include info-level findings

Preview

npx hyperframes preview --background   # agent-safe Studio preview
npx hyperframes preview --status       # is it listening?
npx hyperframes preview --stop         # stop when done
npm run dev                            # human-run foreground preview

Render options

npx hyperframes render --quality draft --output review.mp4
npx hyperframes render --quality looks --output final.mp4
npx hyperframes render --resolution 4k --output master-4k.mp4
npx hyperframes render --format webm --output overlay.webm   # transparent
npx hyperframes render --workers 4 --output final.mp4

Cloud

npx hyperframes cloud render ./project --output video.mp4
npx hyperframes lambda deploy
npx hyperframes lambda render --wait
npx hyperframes lambda progress <renderId>

Inspecting a project

npx hyperframes info                   # project metadata
npx hyperframes compositions           # list compositions
npx hyperframes timeline               # tracks and clips
npx hyperframes audio file.mp4 --read  # where sounds land
npx hyperframes docs gsap              # topics: data-attributes, gsap, compositions,
                                       # rendering, audio, transcribe, troubleshooting

Rules that cause most failures

  • Every timed element needs data-start and a duration, and class="clip".
  • Create the root timeline paused and register it on window.__timelines under the same id as the root element, or you get a still frame.
  • No Date.now(), Math.random() or network fetches.
  • Silent footage and b-roll: muted. Voiceover and music: a separate <audio>.
  • Always run npm run check, then look at snapshots. A passing check does not show how it looks.
