Start a new video

  1. Copy this repo to a new one. Delete video/assets/*, storyboard/ and the old spec doc.
  2. cp templates/project.template.json spec/project.json and fill in every <<...>>.
  3. cp templates/scenes.template.json script/scenes.json and write your scenes.
  4. Add your FAL_KEY to a git-ignored .env if you want fal.ai drafts, then run scripts/gen-backgrounds.sh and scripts/gen-voiceover.sh.
  5. Build the pages (see the commands below), then rewrite the text on index.html, kanban.html and recommendations.html for the new video.
  6. Reset versions.json (site 1.0.0, an empty changelog with one entry) and run node scripts/version.mjs bump minor "new video: ...".
  7. Create the GitHub repo, turn on Pages from main, and push. Work through Preprod, Prod and Postprod, committing, pushing and deploying every change.

What lives where

  • Instructions for AI agents: AGENTS.md (the file is in the repo root; CLAUDE.md points to it).
  • The spec and checklist: Master spec and Release checklist, also as Markdown.
  • What is changing: Changes and the Changelog.
  • Blank files for the next video: templates/ on GitHub.

Things worth changing in the template itself

After each video, write down what slowed you down and fix it in the template: a missing field in project.json, a checklist item you forgot, a rule in AGENTS.md that an agent broke. Release those as a normal version bump so the next video starts better.
